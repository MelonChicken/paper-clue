# 논문갈피

### 쌓이는 논문 속, 이번 주 읽을 한 편의 갈피를 잡다.

주간 연구 브리핑에 쌓인 여러 논문을 분석하고 비교하여  
**지금 나에게 가장 읽을 가치가 있는 논문을 선택하도록 돕는 AI 연구 의사결정 서비스**입니다.

---

## 논문은 계속 쌓이는데, 무엇부터 읽어야 할까요?

연구 브리핑, arXiv, 연구실 공유 자료를 통해 매주 새로운 논문을 발견할 수 있지만
모든 논문을 직접 확인하고 비교하기에는 시간이 부족합니다.

논문갈피는 논문을 더 많이 추천하는 서비스가 아니라,
**이미 발견한 논문들 사이에서 무엇을 먼저 읽을지 판단하도록 돕는 서비스**입니다.

---

## 논문갈피가 하는 일

### 1. 브리핑

주간 연구 브리핑 Markdown을 입력합니다.

- 논문·데이터셋·도구 구분
- 분석할 논문 후보 추출
- 분석 대상 정리

### 2. 분석

각 논문의 연구적 가치를 동일한 기준으로 분석합니다.

- 연구 관련성
- 방법론적 신규성
- 학술적 중요도
- 최근 연구 흐름에서의 위치
- 적용 가치
- 재현 및 구현 가능성

확인된 사실과 AI의 해석을 구분하고,
근거가 부족한 정보는 별도로 표시합니다.

### 3. 결과

후보 논문을 한 화면에서 비교하고 이번 주에 읽을 논문을 선택합니다.

- 논문별 평가 비교
- 평가 근거 확인
- 후보 간 장단점 비교
- 우선 논문 추천
- 사용자 최종 선택

> AI가 논문을 대신 결정하는 것이 아니라,
> 사용자가 더 나은 판단을 내릴 수 있도록 근거를 정리합니다.

---

## 서비스 흐름

브리핑 입력
→ 논문 후보 추출
→ 논문 분석
→ 비교 및 근거 확인
→ 이번 주 읽을 논문 선택

---

## 논문갈피의 핵심 가치

### 발견에서 선택으로

기존 논문 검색 도구가 “어떤 논문이 있는가?”를 찾는 데 집중한다면,
논문갈피는 “그중 무엇을 지금 읽어야 하는가?”에 집중합니다.

### 점수보다 근거

단순한 평가 점수만 보여주는 것이 아니라,
왜 해당 평가가 나왔는지 확인할 수 있는 근거를 함께 제공합니다.

### AI 추천보다 사용자 판단

최종 선택은 사용자가 수행합니다.

논문갈피는 연구자의 판단을 대체하는 AI가 아니라
**논문 읽기 우선순위를 결정하기 위한 Research Decision Support Tool**입니다.

## 로컬 실행

### 사전 요구사항

- Node.js
- npm
- OpenAI API Key

### 1. 의존성 설치

```bash
npm install
````

### 2. 환경 변수 설정

프로젝트 루트의 `.env.local` 파일에 API 키를 설정합니다.

```env
OPENAI_API_KEY=your_api_key_here
```

`.env.local` 파일과 API Key는 GitHub에 업로드하지 마세요.

### 3. 개발 서버 실행

```bash
npm run dev
```

실행 후 터미널에 표시되는 로컬 주소로 접속합니다.

## 프로젝트 방향

논문갈피의 목표는 AI가 연구자의 선택을 대신하는 것이 아닙니다.

새로운 논문이 끊임없이 등장하는 환경에서
**검색 → 검토 → 비교 → 선택** 과정의 반복적인 조사 부담을 줄이고,
연구자가 실제 논문 읽기와 연구에 더 집중할 수 있도록 돕는 것이 목표입니다.
